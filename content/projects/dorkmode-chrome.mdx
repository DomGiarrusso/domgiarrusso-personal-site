## Description

Dorkmode for Chrome brings the palette from my Visual Studio Code theme into
Google Chrome. It is meant for people who want a dark browser without making
every part of the interface pure black.

## Motivation

Chrome (Chromium) is one of the primary browsers I use, but its default dark theme never had the depth or
contrast I wanted. After finishing the Visual Studio Code version of Dorkmode,
using the same palette in Chrome was the obvious next step.

## Development

The project uses a Chrome theme manifest written in JSON. That manifest assigns
the Dorkmode colors to the frame, tabs, toolbar, and new tab page. The finished
theme is published on the Chrome Web Store, and its source is available in the
linked GitHub repository.
