## Description

Task:Timer is a Chrome extension I built to run work and break timers back to
back. It follows the Pomodoro Technique, but lets each person choose the length
of both intervals instead of locking them into a preset schedule.

The extension also accepts an optional repeat count. Once a session starts, it
moves through the work and break intervals for the requested number of cycles.
That removes the need to reopen a clock app and set a new timer every time the
session changes.

## Motivation

I often lose track of time while working on a project and keep going until I am
burned out. The Pomodoro Technique helped, but manually switching between a work
timer and a break timer kept interrupting the routine.

I built Task:Timer to handle that switch for me. It keeps the timer inside
Chrome, where I am already working, and lets me plan several work and break
cycles at once.

## Development

The extension uses HTML, CSS, and JavaScript, with Bootstrap for the interface.
Its controls handle configurable work and break durations, repeat counts,
pausing, stopping, and resetting. Task:Timer is published on the Chrome Web
Store, and its source code is available in the linked GitHub repository.
