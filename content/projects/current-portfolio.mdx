## Case study in progress

This site is the current version of my portfolio. I am building it as a
long-lived home for my work, with project content kept separate from the page
components so both can change without turning every update into a redesign.

## What is already here

The project uses file-based routes and a shared project registry. Individual
case studies live in MDX, while React components handle their common layout,
technology badges, links, and media galleries.

The site also has responsive gallery pages, light and dark themes, reusable UI
components, syntax-highlighted code blocks, and a Cloudflare Workers build.

## Built with

The application uses TanStack Start, React, TypeScript, Tailwind CSS, and
shadcn/ui. Vite builds the client and server bundles for Cloudflare Workers.
