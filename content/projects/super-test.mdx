## Overview

This demo project shows the first pass of the new project-story layout. The hero
keeps the project media prominent, while the article has its own comfortable
reading width.

<Callout title="A constrained MDX component">
  Most content can remain standard Markdown. Components like this callout are
  available when a project needs a richer presentation.
</Callout>

## Implementation notes

Fenced code receives syntax highlighting, a language label, and a copy action
without requiring special markup in the article.

```tsx
export function ProjectSummary({ title }: { title: string }) {
  return <h2>{title}</h2>
}
```

Inline `code`, **emphasis**, links, tables, and other GitHub-flavored Markdown
features continue to work normally.
