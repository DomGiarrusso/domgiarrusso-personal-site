## Description

I rebuilt the Yeti Mouth Games website from the ground up. I implemented a new design for the indie game studio's site,
aligning it more closely to the brand logo. The site is now more responsive and easier to view on desktop, tablet, and mobile devices.
Players can now easily browse games and access the studio's socials.

## Motivation

The previous version of the website lacked a consistent visual design.
It also didn't give the studio's games the focus they deserved.
I reorganized the site around the games catalog and gave every game its own page,
On each of those pages providing links to places where people can play or buy the game.

## Development

I built the site using TypeScript, Next.js (React), and Tailwind CSS.
I used Next.js to Static Site Generation (SSG) so the site can be statically hosted.
This improves SEO while allowing for reusable layouts and templating so new content can be added easier in the future.
