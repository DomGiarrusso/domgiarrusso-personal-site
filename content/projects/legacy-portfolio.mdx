## Description

This is a retired version of my portfolio website. I built it from scratch after
outgrowing an earlier Google Sites page. It gave my projects a dedicated place
and included image galleries and a contact form.

## Motivation

Google Sites was a quick way to publish my work, but it limited how I could
organize projects and control their presentation. Writing the replacement
myself gave me direct control over the page structure, styling, and interactions.

## Development

I built the site with HTML, CSS, and JavaScript. Bootstrap supplied the
responsive layout and common interface pieces. Lightbox 2 handled larger gallery
views, Animate on Scroll added entrance effects, and Formspree processed the
contact form. The linked repository contains this retired version of the site.
